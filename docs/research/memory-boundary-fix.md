# 空库与失败执行证据的修复

2026 年 11 月 13 日，针对 [A1/T1 链路试跑](a1-t1-pilot-results.md) 暴露的两处问题修复实验性 revise 模式。默认提取、检索和批量整理策略不变。当前改动尚未替代原固定版本标记；旧批次结果继续对应各自源码快照。

## 空库有明确的新增路径

记忆 subagent 现在有四个工具：search_memory、read_memory、create_memory、update_memory。初始上下文告知可修订项目笔记数量。没有相关旧笔记时，可以创建新事实，或没有新事实就结束，不需要猜文件名与版本。

create_memory 接收新名称、完整摘要和正文、active/suspect 状态、原因及证据 ID。只创建项目范围的 project 类型事实；名称使用不带扩展名的 kebab-case，拒绝路径及索引保留名。工具校验证据，至少需要一条读取或执行观察。创建在统一锁中检查目标不存在，不覆盖已有文件；相同摘要和正文的重复事实也会被拒绝。索引写入失败会撤销新文件。

update_memory 仍只修改已有笔记，保留先读后写与版本校验。找不到目标时直接说明应搜索或使用 create_memory，不再只要求反复读取不存在的文件。新建后要求读回。最终回复即使格式不合格或触及预算，已经通过工具提交的创建仍计入实际结果；日志分别保留提交和结束状态。

持久项目事实不再通过最终回复中的 memories 数组绕过创建校验。该数组仍兼容其他类型或会话事实。没有为默认机制强制增加项目笔记，也没有修改默认学习期的提取规则。

## 执行失败也是一种观察

证据按工具结果分类，保留原始返回值：

| evidence_kind | 含义 |
|---|---|
| file_observed | 成功读取的文件内容 |
| file_changed | 成功的写入或编辑，可作为辅助证据 |
| command_succeeded | 命令报告成功 |
| command_failed | 命令返回有效非零退出结果，可用于记录观察到的失败 |

非零回执须包含整数退出码、stdout 和 stderr，并且不是权限拒绝、显式工具错误、超时、取消或负退出状态。126/127 这类 shell 调用失败不作为目标程序的执行观察。写入失败仍不能作为成功修改的证据。

例如，测试实际运行四条用例、一个断言失败、退出 1，可以支持“观察到此测试失败”或使旧的成功断言变为待复核。它不能证明任务已成功，也不能单凭失败确定另一条入口。原始 ok=false、退出码、失败输出与 command_failed 标记都进入笔记溯源及日志。

## 存储与日志

memory_revision_decision 新增 created、memory_exists、duplicate_memory、creation_requires_tool 等结果；memory_change 保留真实创建及索引的前后内容。memory_subagent_finished 增加 created 和 error，便于区分落盘成功、回复格式问题及预算耗尽。

保存多行证据时还修复了一个既有解析缺陷：只有第零列的分隔符才结束 YAML frontmatter。stdout/stderr 中缩进保存的三横线不再被误认为元数据结束，正文、证据及索引可正常读回。这是格式读取修复，不改变默认记忆策略。

## 验证及其边界

最终全量测试为 **345 项通过、1 项跳过**。新增回归使用实际 A1 空库观察及 T1 被拒绝提案，覆盖正常新增、无新增退出、重名与别名、取消、索引失败回滚、失败执行与未执行的区分，以及多行证据读回。

只回放了两次真实模型维护，没有重跑十六个后续任务：

- A1 空库：四次请求后正常结束，创建一条正确的 EventBus/通知装配笔记并读回，没有猜版本或反复更新缺失文件。
- T1 失败现场：五次请求后正常结束，选择保持 CI 笔记、按源码补充定价规则，未引用非零执行回执。这次没有 invalid_evidence，但不能把它说成已实测模型主动采用了失败执行证据。

另将原先因非零回执被拒绝的真实 T1 提案确定性重放，不调用模型。它现在提交成功，溯源仍为 ok=false、exit_code=1，并保留失败含义。因此，允许该证据的代码路径已验证，模型主动采用此类证据的稳定性尚未评估。

真实回放之后补充了多行元数据解析修复，以本地测试和确定性重放验证，没有再调用模型。数据保存在当前 worktree 的 .swe-agent/experiments/memory-boundary-fix-01/：maintenance.jsonl、before/after、visible.json、result.json 和 verification.json。sources.zip 对应两次真实维护时的版本，sources-final.zip 对应补充解析修复后的代码。两次真实维护共用服务商返回的 46,446 token。

这些验证说明功能缺陷得到修复，不替代正式行为比较。A1 自然学习没有留下旧笔记的事实仍保留；后续实验需要按是否形成相关旧记忆分层，而非人工补笔记使所有样本看起来都经历了修订。
